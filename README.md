# ACME-Project
For my cybersecurity capstone course, I investigated a ransomware attack scenerio. I analyzed evidence, created a timeline of events, identified root causes, and recommended controls using industry standard frameworks/regulations. 

# Project Summary
The made-up company ACME Corporation Technologies was victim to a ransomware attack, which originated through a successful phishing campaign. A finance employee opened a malicious document which was attached to the phishing email. Once the file was opened, the attacker stole credentials, accessed multiple servers via RDP, and deployed ransomware on a healthcare server containing sensitive patient information. The attacker also exfiltrated large amounts of PII. My report followed the attack from the first phishing email through containment, and post-incident recommendations. This project required a mix of cybersecurity skills: incident response, digital forensics, threat analysis, business impact analysis, and communicating technical information to stakeholders. I mapped the evidence to MITRE ATT&CK techniques, and recommended controls such as configuring proper network segmentation, EDR alert optimization, MFA, firewall rules, and incident response playbooks. This project also gave me room to improve my technical communication skills in a way leadership would understand. Instead of describing the technical steps of the attack which are confusing for non-security professionals, I clearly communicated the possible effects of this breach. In summary, this project was beneficial to me because I am most interested in the GRC side of cybersecurity.
